# Kontribusi

## Aturan
1. Jangan upload data apotek asli (nama supplier + harga beli asli, faktur, data penjualan, data pasien).
2. Gunakan data sintetis: `Paracetamol, stok 50, harga 5000`, bukan data asli.
3. Semua perubahan aturan harus lolos `python test.py` - wajib 15/15.
4. Satu PR untuk satu fitur / perbaikan.

## Cara
1. Fork repo ini
2. Buat branch: `git checkout -b tambah-fitur`
3. Jalankan test: `python test.py`
4. Buat Pull Request dengan deskripsi jelas
